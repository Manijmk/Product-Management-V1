# Backend

This folder is the Codex implementation target.

Locked stack:

- Node.js 24 LTS
- TypeScript
- NestJS
- Fastify
- PostgreSQL
- Prisma + PostgreSQL SQL
- Jest
- Swagger/OpenAPI
- Docker Compose

Before scaffolding, read the repository-level `AGENTS.md` and all `/docs` files.

Do not use this folder to redesign the database. SQL under `/database` is the schema source of truth.
